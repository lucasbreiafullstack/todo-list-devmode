## 🎯 Sobre o Projeto

Este é o **Projeto Integrador 1** do curso DevMode. Você vai criar um aplicativo completo de gerenciamento de tarefas (To-Do List) aplicando **TUDO** que aprendeu até agora.

### O que você vai construir:

Um aplicativo web profissional de To-Do List com:
- ✅ CRUD completo (Create, Read, Update, Delete)
- 🔍 Sistema de busca e filtros
- 💾 Persistência de dados com LocalStorage
- 📱 Design responsivo (desktop, tablet, mobile)
- 🎨 Interface moderna e profissional

## 🚀 Como Começar

### 1️⃣ Clone este repositório
```bash
git clone https://github.com/devmode-curso/taskflow-projeto-devmode.git
cd taskflow-projeto-devmode
```

### 2️⃣ Crie sua branch pessoal
```bash
# Substitua "seu-nome" pelo seu nome (sem espaços)
git checkout -b seu-nome

# Exemplo:
git checkout -b joao-silva
```

### 3️⃣ Configure seu repositório pessoal
```bash
# Remova a conexão com o repo base
git remote remove origin

# Conecte com SEU repositório no GitHub
# (Crie primeiro no GitHub com nome "taskflow-seu-nome")
git remote add origin https://github.com/SEU-USUARIO/taskflow-seu-nome.git

# Verifique
git remote -v
```

### 4️⃣ Faça seu primeiro commit
```bash
git add .
git commit -m "chore: setup inicial do projeto"
git push -u origin seu-nome
```

## 📋 Requisitos Obrigatórios

### Funcionalidades (20 pontos)

- [ ] **Adicionar tarefa** - Input + validação
- [ ] **Listar tarefas** - Renderização dinâmica
- [ ] **Marcar como concluída** - Toggle status
- [ ] **Editar tarefa** - Modificar texto
- [ ] **Deletar tarefa** - Remover com confirmação
- [ ] **Filtros** - Todas / Pendentes / Concluídas
- [ ] **Busca** - Tempo real, case-insensitive
- [ ] **Contador** - Total, pendentes, concluídas
- [ ] **Limpar concluídas** - Deletar em massa
- [ ] **LocalStorage** - Persistir dados

### HTML Semântico (20 pontos)

- [ ] Tags semânticas (`<header>`, `<main>`, `<section>`, `<footer>`)
- [ ] Formulário com `<label>` apropriados
- [ ] Estrutura lógica e organizada
- [ ] Acessibilidade básica

### CSS Responsivo (20 pontos)

- [ ] CSS Variables (`:root`)
- [ ] Layout responsivo (Desktop, Tablet, Mobile)
- [ ] Design profissional
- [ ] Estados hover/focus/active
- [ ] Transições suaves

### JavaScript (30 pontos)

- [ ] Código organizado e limpo
- [ ] Funções com responsabilidade única
- [ ] Manipulação do DOM eficiente
- [ ] Event listeners corretos
- [ ] Try/catch no LocalStorage

### GitHub e Deploy (10 pontos)

- [ ] Repositório no GitHub
- [ ] README.md completo

- [ ] Código comentado

## 🎓 Dicas de Ouro

1. **Planeje antes de codar** (15min de planejamento = 2h economizadas)
2. **Comece pelo MVP** (funcional primeiro, bonito depois)
3. **Teste constantemente** (não deixe para testar tudo no final)
4. **Commits pequenos** (a cada funcionalidade)
5. **Código limpo** (você vai reler depois)
6. **Mobile first** (ou teste mobile desde cedo)
7. **README caprichado** (é seu cartão de visitas)
8. **Design importa** (mas função importa mais)
9. **Peça feedback** (mostre para amigos/família)
10. **Não deixe para última hora!**
